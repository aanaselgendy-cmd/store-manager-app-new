# إدارة المحل — مشروع Android (Flutter)

تطبيق عربي محلي لإدارة الأصناف والمبيعات والمشتريات وسجل العمليات.

## الميزات الموجودة في الكود
- قاعدة بيانات SQLite محلية على الجهاز.
- إضافة أصناف وترتيب وبحث بالاسم.
- بيع يخصم من المخزون مع التحقق من الكمية المتاحة.
- شراء يزيد المخزون ويحدث أسعار القطاعي والجملة.
- سجل تلقائي لعمليات البيع والشراء وتعديل الأسعار مع فلترة حسب النوع واليوم، ولا توجد شاشة لتعديل أو حذف السجل.
- يعمل دون اتصال بالإنترنت بعد التثبيت.

## إنشاء APK تلقائيًا من GitHub Actions
هذا المشروع يتضمن سير عمل `.github/workflows/build-apk.yml` لبناء APK في خوادم GitHub دون تثبيت Flutter على جهازك.

1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2. افتح تبويب **Actions** في المستودع واسمح بتشغيل Actions إذا طُلب منك ذلك.
3. افتح **Build Android APK** ثم اضغط **Run workflow** (أو ادفع تغييرًا إلى `main`).
4. بعد نجاح البناء، افتح صفحة التشغيل الناجح، وانزل إلى **Artifacts**، وحمّل `store-manager-android-apk`.
5. فك ضغط الملف الذي نزلته؛ ستجد `app-release.apk`، وانقله إلى هاتف Android وثبّته.

## بناء محليًا
يتطلب Flutter SDK وAndroid SDK. نفّذ:

```bash
flutter create --platforms=android --project-name store_manager_app .
flutter pub get
flutter build apk --release
```

## تنبيهات قبل استخدامه في المحل
- رقم الباسورد الافتراضي للمشتريات هو `1234`؛ يجب تغييره قبل الاستخدام الحقيقي. شاشة تغيير الباسورد غير موجودة بعد.
- هذه نسخة أولية تحتاج اختبارًا على الهاتف، وإضافة نسخ احتياطي/استعادة قبل الاعتماد على بيانات المحل.
- السجل لا يتيح التعديل أو الحذف من واجهة التطبيق، لكنه ليس مقاومًا للتلاعب أمام شخص لديه وصول تقني مباشر إلى ملفات قاعدة البيانات.
